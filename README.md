# Bardlabs

Internal workspace for ideas, outreach, projects, and SOPs.

## Stack

- [Next.js](https://nextjs.org)
- [Supabase](https://supabase.com)
- Tailwind CSS

## Setup

```bash
pnpm install
cp .env.example .env.local
# Fill in Supabase URL, anon key, and allowed admin email
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
